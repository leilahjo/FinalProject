# Project Status Update Instructions

**Points:** 5

**Objective:**
The goal of this check-in is to ensure you are making steady progress on your project.

**Instructions:**
Please submit a brief update on your project's current status. You do not need to have a fully playable game yet, but there should be evidence of active development.

In your submission, please provide:
1. **GitHub Link:** A link to your forked repository showing your recent commits.
2. **Engine Progress:** A short bulleted list of the engine features from your proposal's complexity matrix that you have started or completed. Please mention specific requirements you are working toward, such as adding a new component to the ECS or implementing animations.
3. **Game Progress:** A short bulleted list of the gameplay features you have been working on.
4. **Blockers:** Are you stuck on anything? Let us know if you need help with specific C++ bugs, Raylib issues, or architectural decisions. If you have no blockers, just state "None."
5. **LLM Usage (If Applicable):** As a reminder, if you used an LLM as an advisor for debugging or planning, you must include a link to the Google Doc containing your entire conversation log. 

**Grading:**
This is a low-stakes assignment designed to keep you on track. You will receive full credit (5 points) for providing a complete update demonstrating some recent commit activity.
